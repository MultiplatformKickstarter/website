How It Works

From prompt to production-ready KMP project

Five steps from idea to exported source code. No cloud required.

1

Describe your app

Write a natural-language prompt describing your app idea, screens, and features. No boilerplate configuration needed.

2

Generate a full KMP project

The generator produces a complete Kotlin Multiplatform project with Compose Multiplatform UI, ViewModels, and KMP architecture — all configured for your targets.

3

Preview and iterate

Review the generated project inside the workspace. Refine with follow-up prompts — "add a search bar", "use a dark theme", "add a favorites screen".

4

Inspect and edit the code

Browse the generated file tree and read the Kotlin code before you export. Your code, your rules.

5

Export ZIP

Download a complete, buildable project ZIP ready to open in Android Studio or IntelliJ IDEA. Git and store publishing workflows are planned.
