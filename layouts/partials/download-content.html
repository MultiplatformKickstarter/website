System Requirements

macOS

  • macOS 13 Ventura or later
  • Apple Silicon or Intel
  • 8 GB RAM minimum (16 GB recommended)
  • Ollama installed for local generation

Windows / Linux

  • Windows 10 / 11 or Ubuntu 22.04+
  • JVM 17+ required
  • 8 GB RAM minimum (16 GB recommended)
  • Ollama or compatible local API

Getting started (once available)

  1. Install Ollama — download from ollama.com and pull a code model: ollama pull qwen2.5-coder
  2. Download Multiplatform Kickstarter — install the desktop app for your platform
  3. Connect your model — point the app at your Ollama instance (default: localhost:11434)
  4. Describe your app — type a prompt and generate your first KMP project
  5. Export and build — download the ZIP and open in Android Studio
